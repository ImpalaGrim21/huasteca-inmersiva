# Fotografías del prototipo

Las fotografías representan sitios reales de la Huasteca Potosina. Verificación: 26 de octubre de 2026. Para reducir espacio y transferencia, los originales se convirtieron a WebP con calidad 78 y se redimensionaron conservando sus proporciones. No se alteró su contenido; la interfaz puede aplicar un encuadre CSS (`object-fit: cover`). Las fotografías conservan su licencia de origen, independiente de la licencia del código. Las seis imágenes finales ocupan 1,051,964 bytes frente a los 2,310,014 bytes de los JPEG descargados (54.5 % menos); sólo se conservan las versiones WebP en el proyecto.
